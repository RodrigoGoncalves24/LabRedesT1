## ReadMe Trabalho 1

* Rode na própria IDE ou compile o projeto com javac Servido/Server.java
* Rode, no terminal, com java Servidor/Server --port xxxx --root ./www 
* Conecte outro terminal com *curl -v http://localhost:xxxx* para se conectar com o servidor conectar
* Posteriormente deverá ser utilizado *curl -v http://localhost:xxxx/ outras / requsicoes* para conseguir informações do server
